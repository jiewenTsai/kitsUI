# kitsUI：KIT 量尺建構工具

kitsUI 是 [kits](https://github.com/jiewenTsai/kits) 的 Shiny 介面。
計算全部交給 kits，kitsUI 只負責畫面、檢查和下載。

四個頁面依序做：

1. ① 資料：上傳長格式資料（可以一次好幾個檔，也收 .csv.gz），勾這一回合的世代與波次。
2. ② 題目校準：沒有題庫時自由校準；有固定檔時，舊題固定在題庫的值，只估新題，並檢查偏移。
   「固定了哪些題」列出每一題的狀態，並核對固定的值和題庫完全相同。
3. ③ 連結：內部連結（M36 → M03）與外部連結（M03 → D）；每條連結只做一次，做好就凍結。
   垂直連結圖會接上之前回合的點。
4. ④ 受試者評分：這一回合的分數、分數對照表、題目表，並下載新的固定檔（zip）。
   題目表可以設定通過步驟（得分至少幾分算通過）。

下一回合上傳新的波次和上一回合的固定檔，從 ① 再做一次。
最後一頁「使用手冊」有完整的操作步驟與截圖（原稿在 `tools/manual/`）。
舊的參數不動，早先的分數也不重算。

一個回合可以一次勾好幾個波次。同一個量尺的各波合在一起做一次固定校準，偏移也合起來判斷。
已經收完的好幾波，建議一次勾；以後每次新收一波，再只勾那一波。
兩種做法的對照與 kitsUI 的處理流程，見使用手冊「任務二 → 一次加好幾波」。

## 0.3.8 的新功能

- ② 每個量尺的結果最上面多了「固定了哪些題」。
  每一題一個狀態：固定（沿用題庫）、固定（不判斷偏移，沿用題庫）、偏移 → 新版本、
  新題（這一回合估計）、這一回合拿掉、自由校準。
  上方有一句核對，例如「固定的 N 題、M 個步驟，參數和題庫完全相同（最大差 0）」。
  有任何固定的步驟和題庫不同時，這一句變成紅框。
  固定的題收在「看全部固定的題」裡（第一回合是自由校準，寫「看全部自由校準的題」）；整張表可以下載成 CSV。
- ② 的「圖」多了「偏移把關圖」。
  橫軸是這一回合自由試算的門檻（固定前），縱軸是題庫的門檻（固定的值）。
  虛線是判斷用的線，灰色帶子是容許範圍；實線是拿掉偏移的步驟之後的線。
  藍色是固定，灰色菱形是固定但不判斷偏移的題，橘色叉叉是偏移 → 新版本，灰色空心圓是沒有判斷的步驟。
- 校準的順序：先不固定任何題、只用這一波自由試算；
  試算的門檻和題庫的門檻比，離 mean/sigma 線太遠的是偏移；
  沒有偏移的題固定成題庫的 beta，所以固定之後門檻和題庫相同；
  偏移的題換成新版本（例如 `lanc09_rR2`），用這一波重新估；最後做固定校準。
  所以偏移是在固定之前判斷的，固定之後的題不會偏移。
- 比的是門檻，不是 beta。同一題的幾個步驟 beta 會一起移動，也可能順序顛倒；
  Thurstonian 門檻比較穩定，也好讀。
- ④ 題目表多了「通過步驟」：得分至少幾分算通過，預設每題是 1。
  0.3.9 起是收起來的區塊：選題目、填通過步驟、按「套用到選的題」；有題目不是 1 時自動打開。
  題目很多時，可以在「用檔案設定」上傳 CSV（item_id、step）或先下載範本；「全部改回 1」回到預設。
  題目表多一欄 `step`，三種門檻與 age50 照它算。
  紅字是設定沒有套用；橘字是這一回合沒有的題，設定照樣存著給之後的回合。
  校準、連結與分數都用全部的分數，不受影響。① 作答設計圖的通過比例也照它算。
  例如之後的認知題是 0–4 分、3 分以上才算通過時用它。
- age50 只從這一回合的資料算：至少兩個波次、通過比例跨過 50%，且在資料的月齡範圍內。
  只有一個波次時是空的，不往外推。
- ③ 垂直連結圖：只有一個世代的回合（例如 M03 84 個月借用 M36 題庫）也畫得出來。
  之前回合的點來自固定檔的各波次摘要，用現在的連結換算；圖上分得出這一回合與之前的回合。
  0.3.8 以前的固定檔沒有摘要，下一回合起或用這一版重跑之前的回合後才有。
- 固定檔多了兩個檔：`wave_summary.csv`、`pass_steps.csv`（見下面「固定檔」）。
- 0.3.6–0.3.7：① 上傳失敗時有「開啟 kitJoin」按鈕；程式碼字型改用 M PLUS Code Latin；
  ③ 內部連結的獨立檢核（kits_link_check()）預設收起來。

## 固定檔

④ 頁下載的 `kitsui_fixed_R1.zip`、`kitsui_fixed_R2.zip`… 是同一把尺。
下一回合一定要上傳它。請不要解壓縮後修改再壓縮。

| 檔案 | 內容 |
| --- | --- |
| VERSION | 版本、建立日期、各回合名稱、參照世代、量尺 |
| bank.csv | 題庫：每個量尺每一題每一步的 beta 與標準誤 |
| versions.csv | 題目版本：偏移的題原來的題號與新的題號 |
| waves.csv | 每個題庫校準過的波次 |
| wave_summary.csv | 各量尺、世代、波次的人數、能力值的 P25、中位數、P75（校準的量尺上）與實際月齡的中位數（0.3.11 起）；只有摘要，沒有個人資料 |
| pass_steps.csv | 通過步驟；沒列的題用 1。下一回合沿用；新版本用原來那一題的設定 |
| links.csv | 連結的點與設定 |
| checks.csv | 每一回合的檢查紀錄 |
| README.txt | 固定檔的說明 |

- 固定檔會累積：R2 的固定檔已經包含 R1 的題庫、連結、波次。做 R3 時只上傳 R2 的固定檔。
- 固定檔裡的內容和 README.txt 都是英文，打開不會是亂碼。
  要放中文的 CSV（例如自己的中文題號或領域名稱）用 UTF-8 BOM 寫出，Excel 打開也正常。
  app 的畫面仍然是中文。

## 安裝與執行

```r
install.packages("remotes")
remotes::install_github("jiewenTsai/kits")
remotes::install_github("jiewenTsai/kitsUI")
kitsUI::run_kitsui()
```

Windows 也可以雙擊 `run.bat`（第一次會自動安裝需要的套件）。
下載圖檔（HTML）需要 pandoc；裝了 RStudio 或 Quarto 就有。

## 資料格式

長格式，一列是一個列次（一個孩子的一個波次）的一題作答。

手上的資料是寬格式（一題一欄）、欄名不一樣，或分數不是從 0 開始時，
先用 [kitJoin](https://jiewentsai-kitjoin.share.connect.posit.cloud/) 的「⑥ 轉成 kits 作答檔」轉好再上傳。
① 資料頁的上傳說明和紅字裡也有「開啟 kitJoin」按鈕。

| 欄位 | 必填 | 意思 |
| --- | --- | --- |
| visit_id | 是 | 列次編號，每個孩子的每個波次不同 |
| subj_id | 否 | 孩子編號 |
| cohort | 是 | 世代，例如 M03、M36 |
| sex | 否 | 性別 |
| wave_m | 是 | 波次（施測月齡） |
| age_m | 否 | 實際月齡 |
| item_id | 是 | 題號 |
| item_score | 是 | 得分，從 0 開始的整數 |
| domain | 是 | 領域，例如 lan、motor、cog |

① 頁可以下載欄位範例檔。
外部連結用 `kits::kits_anchors()` 的錨題，領域名稱要和它一致（lan、motor、cog）。

## 雲端部署

`app.R` 是 Posit Connect Cloud 的主檔，`manifest.json` 記錄套件版本。
新增或移除 `R/` 的檔案、或更新套件後，請重新產生 `manifest.json`：

```r
rsconnect::writeManifest(appPrimaryDoc = "app.R")
```

雲端版只能上傳已去識別化的資料。
